## Selection Criteria

All **16 unguided single-agent Main runs** (`codex / gpt-6-astra / xhigh` and `claude-code / claude-opus-5-5 / max`) across the 8 SGLang-Omni benchmark tasks (8 model checkpoints, 7 model families) are included. Preparation/calibration runs, guided prompt ablations, and multi-agent framework runs are excluded so every entry reflects unguided single-agent optimization against its initial 3-repetition baseline B₀.

## Run Notes

- **Comparison window.** These records preserve the original budgets and full-run maxima. Use the [24-hour results](README.md) for the aligned comparison; later scores do not replace scores within that window.
- **Hardware.** All runs in this suite used one H100 80GB HBM3 GPU. Each run retains its own initial B₀ calibration.
- **Cancelled runs.** Qwen3-ASR and Whisper Claude Code runs stopped after approximately 24.0–24.4 h. Their full-run records retain the best score verified before cancellation.
- **Selection.** Calibration runs, guided-prompt ablations and multi-agent runs are excluded.
