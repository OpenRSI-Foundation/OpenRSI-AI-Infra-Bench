## Selection

Match `codex / gpt-6-astra / xhigh` or `claude-code / claude-opus-5-5 / max` in the run plan, and require `install_stop_hook: true` to exclude the ASR preparation runs. Select the maximum numeric `best_score` among archived `final_result.json` files in each task/agent group. Verify that its selected submission report has `status: completed` and the same score. Preserve all qualifying attempts, including null scores and failed/cancelled terminal states, in the CSV. Runs without an archived final result are not included in this snapshot.

This is best-observed historical performance, with unequal attempts, hardware and budgets. It is not a controlled ranking or a new reproduction. The Main sheet also contains an Omni model outside SGNOMI; that model is outside this migration.
